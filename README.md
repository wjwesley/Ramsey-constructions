# Ramsey constructions
This repository contains code, constructions, and other data related to several of my Ramsey theory papers. If there is something you need that is missing from here, or if any formatting is unclear, please don't hesitate to email me.

Files with the .g6 file extension are graphs written in the graph6 format (see https://users.cecs.anu.edu.au/~bdm/data/formats.html). Other files are given either as adjacency matrices or strings where the above-diagonal entries of the adjacency matrix are written in column-major order: (0,1), (0,2), (1,2), (0,3), (1,3), (2,3), etc. 

### Graph notation

* $K_n$ is the complete graph on $n$ vertices.
* $C_n$ is the cycle graph on $n$ vertices. 
* $J_n = K_n -e$ is the graph obtained by removing one edge from $K_n$. 
* $B_n = K_2 + \overline{K_n}$ is the book graph, which consists of $n$ triangles sharing a common edge.
